## Стек и процесс
- Статические шаблоны в этой репе (HTML/CSS/JS), затем ручной перенос в WordPress:
  Bricks Builder (шаблоны + код-блоки) + тема SNN BRX (сниппеты кода).
- Vanilla JS ES6+, plain CSS. Без jQuery, фреймворков, сборщиков.
- Шрифты: Oswald (заголовки) + Manrope (текст) + JetBrains Mono (теги, цены).
- ИИ-кодер работает задачами/PR; память между сессиями = ТОЛЬКО AGENTS.md + этот memory bank.
