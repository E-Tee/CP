**Технические правила:**
1. **H1 ровно один** на страницу. H2/H3 строго по порядку, без перескоков уровней.
2. **Хлебные крошки** на всех страницах кроме главной; последняя крошка — без ссылки; видимые крошки дублирует JSON-LD `BreadcrumbList`.
3. **URL услуг плоские** (`/uslugi/{slug}/`), логика вложенности задаётся крошками и меню, а не URL.
4. **Canonical** каждой страницы = её собственный URL без параметров. Robots: index, follow (noindex только у `/404/` и политики).
5. **Изображения:** WebP, `loading="lazy"` + `decoding="async"` для всех, кроме hero первого экрана (hero — preload + `fetchpriority="high"`, это LCP). Явные `width/height` (CLS=0). Декоративные иконки — `alt=""`.
6. **Заглушки изображений:** везде, где стоит `[ЗАГЛУШКА: /img/...]`, вставь плейсхолдер с указанным путём, пропорциями и **обязательным alt из этого документа** (alt построен по семантическому ядру: ключ + материал + гео).
7. **Форма захвата одна** на странице (`id="calc"`), все CTA-кнопки «Рассчитать» — якоря на неё. Поля: имя, телефон (маска +7), загрузка фото (`accept="image/*" multiple`), чекбокс ПД со ссылкой на `/politika-konfidencialnosti/`; honeypot, ajax-отправка.
8. **Цены в текстах — вилки-заглушки**, синхронные между страницами и JSON-LD (`OfferCatalog`). Подставь реальные до публикации.
9. **Антиканнибализация:** в Title/H1 хаба и категорий нет ключей конкретных услуг — они живут только в анкорах карточек.
10. **Footer-меню** (сквозной): услуги (6 категорий + топ-услуги), объекты, цены, оборудование, о компании, выезд, контакты, блог, политика, карта сайта + NAP-блок.
11. **Якорные ссылки на блоки (сквозное правило):** у каждого смыслового блока страницы — стабильный `id` по таблице §2.0; все внутрестраничные ссылки (шапка, кнопки hero, меню «Быстрые ссылки», перелинковка) ведут только на эти id. Класс-хук для скролла — `.anchor`. Отступ под sticky-шапку: `scroll-margin-top: 88px` (+ `html{scroll-behavior:smooth}`). Нумерация блоков в тексте ТЗ — НЕ часть id (например, блок 6 главной = `#price`, без цифр).

## 2.0 ТАБЛИЦА ЯКОРЕЙ БЛОКОВ (единая для всего сайта)

Правила:
- id ставится на секцию `<section class="sec anchor" id="...">`; дубли id внутри одной страницы запрещены.
- Кнопки «Все услуги и цены» → `/uslugi/#uslugi`; «Полный прайс-лист» → `/price/#tables`; «Смотреть примеры работ» → `/{категория}/#cases`; кейсы из услуг/категорий → `/obekty/#objects`.
- Hero каждой страницы получает якорь `#top` (кнопка «наверх» в футере и 404 → `{url}#top`).
- В шапке главной: Услуги→`#uslugi`, Объекты→`#objects`, Цены→`#price`, Оборудование→`#equipment`, О компании→`#why`, Контакты→`#calc`; на остальных страницах те же пункты ведут на страницы (`/uslugi/`, `/obekty/`, `/price/`, `/oborudovanie/`, `/okompanii/`, `/kontakty/`). Пункт «Почему выбирают нас» в hero-меню главной ведёт на `#why`, но карточка этой секции ссылается на `/okompanii/#permits`.

## 2. ШАБЛОНЫ СТРАНИЦ (типовая структура блоков сверху вниз)

7. **`#faq`** — H2 «Частые вопросы» — 3–4 вопроса (H3) + ответы; JSON-LD `FAQPage`
8. **`#calc`** — H2 «Рассчитать стоимость: {услуга}» — форма захвата

## 17. ЧЕК-ЛИСТ ПРОВЕРКИ ЯКОРЕЙ (для кодера и приёмки)

1. Каждая секция страницы обёрнута в `<section class="sec anchor" id="{якорь}">`; id взяты строго из §2.0 и колонок «Якоря блоков» (§5, §6, §7, §15); дублей id на странице нет.
2. Все CTA вида «Рассчитать стоимость / Получить расчёт» ведут на `#calc` этой же страницы; кросс-страничные якоря оформлены как `/путь/#id` (например, `/price/#tables`).
3. CSS: `html{scroll-behavior:smooth}` и `.anchor{scroll-margin-top:88px}` — якорь не прячется под sticky-шапку.
4. Внутренние ссылки меню «Быстрые ссылки» (hero главной и хабов) совпадают с фактическими id (валидатор: парсер HTML + проверка `href^="#"` → существование `id`).
5. Якоря не ломают canonical: `?`-параметры и `#`-хвосты не попадают в canonical/OG:url/sitemap.xml.
6. После сборки прогнать аудит: на каждой странице ≥ 3 якорных ссылки и у каждого смыслового блока свой id; битых `#`-ссылок = 0.
